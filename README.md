# MellClicker — Нативная iOS игра-кликер

Официальный релиз MellClicker (Версия 1.0.0). Это нативная игра-кликер для iOS, разработанная с использованием SwiftUI и AVFoundation с применением чистой архитектуры MVVM.

## Что нового в релизе 1.0.0
- Полностью рабочие звуковые эффекты (работают даже в беззвучном режиме iPhone)
- Установлены новые оригинальные иконки приложения и основная кнопка Mellstroy
- Исправлен интерфейс магазина (устранены ошибки отображения больших чисел)
- Улучшенный баланс игры (новые формулы покупки улучшений)
- Корректный Bundle ID: com.vitya.mellclicker

## Установка (.ipa)
Скачайте готовый файл `MellClicker.ipa` из раздела **Releases** на GitHub. 
Для установки приложения на ваше iOS устройство (iPhone/iPad) используйте любой удобный инструмент для сайдлоадинга:
- AltStore
- Sideloadly
- TrollStore
- Scarlet

## Архитектура проекта
Проект написан на SwiftUI с использованием паттерна MVVM и готов к сборке в Xcode 15/16.

- **App**: Точка входа приложения и координация табов.
- **ViewModels**: Управление реактивным состоянием, таймеры пассивного дохода и локальное сохранение прогресса в UserDefaults.
- **Services**: Высокопроизводительный пул AVFoundation для проигрывания звуков (AudioManager) и Taptic Engine (HapticManager).
- **Views**: UI интерфейс приложения (Экран кликера, Магазин, Настройки).
- **Resources**: Ассеты (кнопка, иконки) и аудио файлы (tap.mp3, chekunec.mp3).

## Сборка в Xcode
1. Откройте `MellClicker.xcodeproj` в Xcode.
2. Выберите симулятор или подключенное устройство.
3. Нажмите **Command + R** для компиляции и запуска.
