# MellClicker — iOS Clicker Game

Релиз MellClicker (Версия 1.0.0). Нативная игра-кликер для iOS, разработанная на SwiftUI и AVFoundation с чистой архитектурой MVVM.

## Список изменений (v1.0.0)
- 3D Кнопка кликера: Интерактивная кнопка с физикой микро-наклона, металлическим кантом и оптимизированными шейдерами.
- Баланс и интерфейс: Скорректированы отступы экрана, баланс опущен ниже для комфортного восприятия.
- Combo HUD: Панель множителей комбо-серий с возможностью отключения в Настройках.
- Магазин улучшений: Прокачка силы клика («Чекушка») и пассивного дохода («Чекунец»).
- Таблица лидеров: Синхронизация рекордов и просмотр глобального рейтинга игроков.
- Оптимизация производительности: Снижена нагрузка на CPU и GPU, устранен нагрев устройства и оптимизирован расход батареи.
- Кастомизация: Поддержка темной и светлой темы, выбор акцентного цвета и тактильного отклика.

## Установка (.ipa)
Скачайте файл `MellClicker.ipa` из раздела Releases на GitHub.
Установка поддерживается через любой инструмент для сайдлоадинга:
- AltStore / SideStore
- Sideloadly
- TrollStore
- Scarlet / GBox / ESign

## Архитектура проекта
- App: Точка входа приложения и навигация по табам.
- ViewModels: Управление состоянием игры, таймеры дохода и сохранение прогресса.
- Services: Сервис воспроизведения звуков (AudioManager) и тактильного отклика (HapticManager).
- Views: Интерфейсы экранов (Кликер, Магазин, Таблица Лидеров, Настройки).
- Resources: Ассеты и аудиофайлы.

## Сборка в Xcode
1. Откройте `MellClicker.xcodeproj` в Xcode.
2. Выберите симулятор или подключенное устройство.
3. Нажмите Command + R для компиляции и запуска.
